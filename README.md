## Firmware

[*Generated by Shield Wizard for ZMK*](https://shield-wizard.genteure.workers.dev)

Reproducible builds with [Nix](https://nixos.org) thanks to [lilyinstarlight/zmk-nix](https://github.com/lilyinstarlight/zmk-nix):

```sh
# flash firmware with xiao dongle, resetting each board first
nix run .#flash reset reset reset dongle left right

# flash firmware with left as central, resetting each board first
nix run .#flash reset reset left_central right

# build all firmware and flash it yourself
nix build .#firmware
```

## Build Guide

### 1. SMD Solar Components & Switch Diodes

A stencil can be used to place paste for these components, so they should done first to allow a stencil to sit flush against the PCB.

The placement of some components will differ by hand. See table below:

| Description                            | Left Hand | Right Hand |
|----------------------------------------|-----------|------------|
| Boost Converter, Capacitors, Resistors | Bottom    | Top        |
| Diodes, Inductor                       | Top       | Top        |

### 2. Solar Cell Mounting & Wiring

- Stiffen silicone wire ends: small drop of super glue, pull to wick inward, cure.
- Feed wires through relief + plated holes (use soap if friction).
- Solder pads first (hot glue melts under iron).
- Clean flux (IPA) before hot glue.
- Apply hot glue for strain relief and joint insulation AFTER solder.

### 1. Preparation
- Inspect PCBs; identify components to be used on the top and bottom. (hotswap sockets, MCU underside, jumpers).
- Verify solder jumpers: bridge on PCB bottom (opposite of the MCU). Ground jumper orientation was previously mistaken.
- If needed, enlarge solar cell wire feedthrough holes (24 AWG → 22 AWG) before assembly.
- Dry‑fit battery, MCU sockets, hotswap sockets to confirm clearances (battery must not sit under key travel; solar cell area clear of mask pours).


### 2. Tools & Consumables
- Hot air rework station (≈300–325 °C for paste reflow).
- Fine tip soldering iron (≈340–350 °C for through‑hole/hotswap).
- Solder paste + spreader (stencil for small SMD only; exclude hotswap socket apertures).
- Flux (no‑clean plus additional for rework), desoldering braid.
- Tweezers (fine ESD), side cutters, sewing needle (for tape perforations).
- Isopropyl alcohol + swabs (flux removal).
- Optional: acrylic conformal coating / insulating paint for unused exposed pads (apply after top-side reflow and cleaning).
- Hot glue (post‑solder strain relief—not before).
- Super glue (wire tip stiffening).
- Soap (temporary lubricant for wire feedthrough).
- Drill (if hole enlargement required).

### 3. Assembly Order (Top Side SMD)
Recommended placement after applying paste:
1. Diodes (D1–D17) – orientation: diode bar aligns with PCB’s solid silkscreen bar.
2. Inductor (LBST1) – ensure reversible footprint pads fully wetted.
3. Capacitors: 4.7 µF (CHV1, CSTOR1), then 10 nF (CBYP1, CREF1).
4. High value resistors: 3.83 MΩ (ROC2, RUV1), 16 MΩ (ROC1), 6.04 MΩ (RUV2), 5.49 MΩ (ROV2), 4.2 MΩ (ROV1).
5. BQ25504 (U1) – align thermal pad; ensure vias in pad are tented or properly filled.
Reflow at ~320–325 °C hot air (increase dwell for large inductor). Inspect joints; touch‑up with iron if needed.

### 4. Diodes & Rework Notes
- If a single diode is placed early for alignment, remove before full stencil pass (stencil must sit flush).
- Keep board elevated (avoid silicone mat heat bubble issue).
- For bottom‑side diodes (if any relocated): one lead may pass through switch LED window—trim after solder.

### 5. Hotswap Socket Installation (Hand Solder)
- Do NOT reflow with paste (plastic softens ~260–270 °C).
- Light flux on pads, optionally pre‑tin pads for faster wetting.
- Seat each socket flat; solder anchor pad first, then remaining.
- Inspect for solder wicking into contact cavity (avoid).

### 6. MCU Socketing & Pogo Pins
- Tape over MCU through‑hole array when soldering pogo pins for battery/reset to prevent accidental fill.
- Insert pogo pins; flux; solder top side; flip and reinforce from underside.
- Install machined female header / low‑profile sockets: support from below so they sit flush; tack one pin, verify flushness, finish opposite corners then remainder.
- Prepare MCU: insert Mill‑Max pins through taped holes (needle to pierce); avoid bending.

### 7. Solder Jumpers
- Bridge only on bottom side (same side as hotswap sockets) after verifying orientation. Use minimal solder to avoid accidental shorts to adjacent pads.

### 8. Battery Contacts / Cutout
- Ensure cutout matches chosen LiPo dimensions (e.g. 25×15×4 mm or recessed AAA strategy).
- If using custom leaf‑spring + recessed contact: align centers ~43.99 mm (AAA spec minus tolerance).
- Support contacts mechanically (frame or zip tie during test fits). Replace temporary ties with final retention once electrical continuity confirmed.

### 9. Solar Cell Mounting & Wiring
- Stiffen silicone wire ends: small drop of super glue, pull to wick inward, cure.
- Feed wires through relief + plated holes (use soap if friction).
- Solder pads first (hot glue melts under iron).
- Clean flux (IPA) before hot glue.
- Apply hot glue for strain relief and joint insulation AFTER solder.

### 10. Cleaning & Pad Protection
- After top-side reflow and flux removal, coat unused exposed copper pads with thin acrylic / conformal layer to reduce accidental shorts (avoid functional pads, test points, pogo interfaces).
- Ensure coating fully cured before hot glue or final assembly.

### 11. Common Issues & Fixes
- Melted hot glue on joints: always solder first, glue after.
- Mis-bridged jumpers (wrong side): remove with braid; redo on correct side.
- Poor pogo pin wetting: reflow from opposite side with added flux.
- Solar wire insertion difficulty: enlarge holes pre‑assembly; stiffen and lubricate.
- Solder bridges on fine pitch IC: add flux, drag solder, wick excess.
- Weak diode joints after long hot air dwell: reflow briefly with iron + flux.

### 12. Final Hardware Checks
- Continuity: each row ↔ diode ↔ column through socket.
- No unintended shorts under BQ25504 (thermal pad vias).
- Pogo pins spring action intact; battery voltage present at MCU BAT pads.
- Hotswap sockets: mechanical retention + unobstructed contact wells.
- Solar cell open‑circuit voltage reaches expected level; harvester input pins correct impedance.
- Acrylic coating not on mating surfaces or jumpers.

### 13. Post-Assembly
- Install key switches; test matrix before mounting battery permanently.
- Mount battery (adhesive or bracket) after successful matrix + charge test.
- Optionally add bottom plate/standoffs (insulate metal regions to prevent shorts).

### 14. Minimal Rework Strategy
- Prioritize inspection right after each subsystem (SMD pass, sockets, pogo interface) to limit cascading faults.
- Keep flux residues off high impedance resistor network (solar MPP setting).
