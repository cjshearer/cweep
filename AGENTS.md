# AGENTS.md

Split ergonomic keyboard repo: ZMK firmware, a KiCad PCB (`cweep.kicad_pcb`), and a
CadQuery-generated case (`cweep.py`).

## Case design

The case is generated by `cweep.py`, with cutout geometry read from the PCB (the PCB is the source
of truth for component placement and sizes). There is no test suite; results are validated
visually and by inspecting the exported geometry.

Tooling lives in the `.#case` dev shell (CadQuery, kiutils, ocp-vscode, kicad, ruff). Run commands
through it — `python`/`ruff` are not on the base PATH:

```sh
# build the model
nix develop .#case --command python cweep.py

# show the model in VS Code via ocp-vscode (requires the OCP CAD Viewer extension connected)
nix develop .#case --command python cweep.py -p

# live-reloading web viewer at http://127.0.0.1:3939 (also renders the PCB via kicad-cli)
nix develop .#case --command python cweep-dev.py

# lint
nix develop .#case --command ruff check cweep.py
```

STEP/STL/DXF exports into `case/` are at the bottom of `cweep.py`.

### Script structure

`cweep.py` is a flat top-level script (no `main()`): running it builds everything, and `-p` shows
it. Broadly: parse PCB -> build 2D `Sketch`es per feature/layer -> build solid shells -> apply
per-feature 3D cutouts -> mirror to make the left half.

- `feature_sketch[name][layer]` — 2D sketches extracted from footprints, keyed by
  `FEATURE_NAME_BY_LIB_ID`.
- `footprint_placements[name]` — `cq.Location`s for each footprint.
- Final solids: `bottom_plate`, `top_plate_right`, `top_plate_left`.

### Conventions and gotchas

- **Coordinates**: KiCad's Y axis is flipped relative to CadQuery, so Y is negated when converting
  footprints/pads. Z=0 is the bottom of the bottom plate.
- **`Sketch` selection is stateful**: `.faces()/.wires()/.vertices()` set a selection that
  subsequent calls operate on (e.g. `.faces(c).vertices(">Y")`), and `.val()`/`.vals()` read it.
  Reusing a sketch object after selecting on it can give surprising results — call `.reset()` to
  start a fresh selection.
- **`offset_profile`** offsets a sketch's outline by a distance (working around an OCC offset bug);
  use it for consistent clearance on outlines rather than hand-rolled offsets.
- **Selecting faces/edges**: prefer idiomatic selectors (`faces("-Z")`, `.faces("<X")`,
  `NearestToPointSelector`, `cq.selectors.*`) over `filter(lambda ...)`, which loses
  orientation/position semantics.

### Validating changes

With no test suite, exec the script and inspect the resulting solids:

```sh
nix develop .#case --command python - <<'PY'
import cadquery as cq
ns = {"__file__": "cweep.py"}
exec(open("cweep.py").read(), ns)
sol = ns["top_plate_right"].val()
print(sol.isValid(), sol.Volume(), len(sol.Faces()))
print(sol.isInside(cq.Vector(11.0, -48.0, 8.2)))  # point-inside checks
cq.exporters.export(ns["top_plate_right"], "/tmp/top.step")
PY
```

To compare before/after geometry, export STEP from both and compare volume/face count, or use the
boolean symmetric difference (`a.cut(b).Volume() + b.cut(a).Volume()` should be ~0 for
equivalently-built solids).
